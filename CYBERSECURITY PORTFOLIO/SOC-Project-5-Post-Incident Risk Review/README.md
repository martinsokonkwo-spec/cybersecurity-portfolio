# Post-Incident Risk Review and Lessons Learned

## Objective
To perform a post-incident analysis to identify control gaps, assess residual risk, and recommend improvements to prevent future incidents.

## Scenario
Following a resolved security incident, the organization conducts a formal post-incident review to strengthen its security posture.

## Key Tasks Performed
- Reviewed incident timeline and response actions
- Identified root causes and control failures
- Assessed residual and future risk
- Proposed corrective actions and control improvements

## Tools & Frameworks
- Post-incident review methodology
- Risk management principles
- Continuous improvement practices

## Deliverables
- Post-incident risk review document
- Lessons learned and remediation recommendations

## Outcome
This project demonstrates maturity beyond incident response, highlighting governance awareness, risk management, and continuous security improvement capabilities.
