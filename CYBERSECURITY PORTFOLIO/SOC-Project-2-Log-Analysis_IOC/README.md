# Log Analysis and Indicators of Compromise (IOC) Identification

## Objective
To analyze security logs in order to detect malicious activity and extract Indicators of Compromise (IOCs) that support investigation and threat detection.

## Scenario
System and network logs indicate abnormal behavior. The analyst must review log entries, identify suspicious patterns, and extract relevant IOCs.

## Key Tasks Performed
- Analyzed log data for anomalies
- Identified suspicious IP addresses, domains, and activities
- Extracted and documented Indicators of Compromise (IOCs)
- Linked findings to potential attack techniques

## Tools & Frameworks
- Log analysis techniques
- Threat detection concepts
- IOC identification methodology

## Deliverables
- Documented list of identified IOCs
- Analysis summary explaining suspicious indicators

## Outcome
This project demonstrates foundational threat-hunting skills, attention to detail, and the ability to support investigations through evidence-based log analysis.
